# 📊 GDP and Productivity of Indian Cities

An interactive data analytics platform that visualizes the economic performance of major Indian cities through Power BI dashboards. The application provides insights into GDP trends, employment, R&D expenditure, sector-wise contributions, and unemployment statistics while offering secure user authentication and an interactive web interface.

## ✨ Features

- Secure user login and registration
- Interactive Power BI dashboard integration
- GDP trend analysis across Indian cities
- R&D expenditure analysis
- Employment and unemployment insights
- Sector-wise GDP contribution analysis
- User feedback collection
- Responsive Streamlit web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Power BI
- MongoDB
- PyMongo
- bcrypt
- Pandas
- python-dotenv
- dnspython
- HTML & CSS
